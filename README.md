# Construction_Price_Prediction
Construction Price Index Prediction using Machine Learning

This project predicts the Construction Price Index based on economic and construction-related features. It uses a Random Forest Regressor trained on historical data and evaluates model performance using MSE, R², and cross-validation. The model is saved as a pickle file for easy deployment and can be integrated into applications like Streamlit for interactive predictions.

Key highlights:

Uses multiple features like Construction Price Index, Building Permits, GDP, Urban Population, etc.

Models compared: Linear Regression, Decision Tree, Random Forest.

Performance metrics used: MSE, R², Cross-Validation scores.
